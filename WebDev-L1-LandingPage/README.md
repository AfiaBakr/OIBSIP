# AFIA_BLOGS — Landing Page

A responsive marketing landing page for **AFIA_BLOGS**, a fictional community blogging platform. Built as part of the Oasis Infobyte Web Development Internship (Level 1).

## Overview

The page introduces AFIA_BLOGS with a hero section, feature highlights, an about/stats section, reader testimonials, a call-to-action, and a footer with contact and social links.

## Sections

- **Navbar** — sticky header with brand logo and anchor links to each section.
- **Hero** — headline, subheadline, and primary CTA button.
- **Features** — three cards covering illustrated posts, community engagement, and secure authentication.
- **About** — platform description alongside key stats (stories published, active writers, monthly readers).
- **Testimonials** — quotes from sample users with avatar initials.
- **Call to Action** — closing prompt encouraging sign-up.
- **Footer** — brand recap, navigation links, contact info, and social links.

## Tech Stack

- HTML5
- CSS3 (custom styles, no framework)
- Google Fonts (Playfair Display, Inter)

## File Structure

```
WebDev-L1-LandingPage/
├── index.html   # Page markup and content
├── style.css    # Styling and responsive layout
└── README.md
```

## Running Locally

No build step is required. Simply open `index.html` in a web browser, or serve the folder with a local static server, e.g.:

```bash
npx serve .
```
